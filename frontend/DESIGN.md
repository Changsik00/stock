# 프론트엔드 디자인 가이드 (look & feel 유지용)

시각 언어: 플랫, 1px 얇은 테두리, 999px 필(칩·탭·버튼), 12~13px 작은 폰트, 그림자·그라데이션 없음.
색은 의미가 있을 때만 쓴다. 모든 색은 `src/index.css`의 변수로만 참조한다(하드코딩 금지).

## 토큰 (라이트 / 다크는 `:root`, `prefers-color-scheme`, `[data-theme]` 세 블록에 동일 이름으로 정의)

| 토큰 | 용도 |
|---|---|
| `--page` / `--surface` | 페이지 배경 / 카드·모달 배경 |
| `--text-primary` / `--text-secondary` / `--text-muted` | 본문 / 보조 / 비활성·캡션 |
| `--border`, `--grid`, `--axis` | 카드 테두리 / 격자·눌림 배경 / 컨트롤 외곽선 |
| `--chip-bg` | 칩·hover·active 배경 |
| `--series-price`, `--series-value` | 가격·거래대금 시리즈, 포커스 링, 활성 탭 밑줄 |
| `--up`, `--down` | 가격 방향 전용: 상승/매수=빨강, 하락/매도=파랑 (한국 관행) |
| `--warn-text` | 배경 위 주황 경고 글자(변동성 고조, danger hover) |
| `--badge-*-bg/fg` | 분류 배지(코스피/코스닥/ETF/선물/live/warn/info) |
| `--risk-*` | KRX 규정 임계 경보 배너 전용 |
| `--btn-primary-bg/-hover/-fg` | 주 동작 버튼 (라이트 #1f66bf+흰 글자, 다크 #3987e5+검정 글자) |

## 컴포넌트 사용 규칙

- **버튼 `.btn`** (필, 36px / `.btn-sm` 32px). 한 영역에 `.btn-primary`는 하나만.
  - `.btn-primary`: 화면의 주 동작(승인, 저장, 추가).
  - `.btn-secondary`(기본): 보조 동작(수정, 수정 후 승인, 뉴스 수집).
  - `.btn-ghost`: 취소, 더보기 등 저강도 동작.
  - `.btn-danger`: 삭제, 무시 등 되돌리기 어려운 동작. 평소엔 중립, hover 때만 `--warn-text` 주황. 빨강/파랑 금지.
  - `.btn-link`: 펼치기/접기 같은 텍스트 링크형.
- **필터·토글·탭**: `.toggle-chip`, `.tab`, `.range`, `.page-tab`. 선택 상태가 있는 컨트롤은 버튼이 아니라 이것들을 쓴다.
- **배지 `.badge-*`**: 읽기 전용 상태 표시. 클릭 동작은 버튼으로.
- **카드/타일**: `--surface` + `1px solid var(--border)` + 8~10px 라운드. 클릭 가능한 KPI는 `.kpi-tile`.

## 색 의미 규칙

`--up/--down`은 가격 방향 전용(버튼·분류·상태 표시에 쓰지 않는다). 주황(`--warn-text`, `badge-warn`)은 주의/경고. 회색은 중립. 글자를 투명도로 흐리게 하지 말고 `--text-secondary/-muted` 토큰을 쓴다.

## 새 UI 추가 시

1. 기존 클래스를 먼저 찾고, 없을 때만 새로 만든다. 인라인 style 색 지정 금지.
2. `<button>`에는 항상 `type`과 `.btn` 계열 클래스를 붙인다(기본 브라우저 버튼 금지).
3. 터치 타깃 높이 32px 이상, 키보드 `:focus-visible` 링 확인.
4. 라이트·다크 둘 다 본다: 글자 대비 4.5:1 이상(큰 글자 3:1), disabled 상태, hover/active, 빨강/파랑이 가격 외 의미로 쓰이지 않았는지.
5. 새 토큰은 세 테마 블록에 모두 추가한다.

## 모바일형 방향 (시범, 2026-11-08)

방향: 토스/네이버 증권처럼 "화면마다 핵심 숫자 하나"를 가장 크게 보이게 하는 친근한 모바일형. 위 look & feel(플랫, 1px 테두리, 토큰 색)은 유지하고 그 위에서 진화시킨다.
**시범 범위**: 대시보드 최상단(변동성 레짐 카드, 지수 타일, 투자자별 수급 요약 타일)과 내러티브 탭. 새 스타일은 `.m-font`/`.mt-*`/`.vr-*`/`.narr-page` 범위로만 적용했고 기존 `.kpi-tile`·`.section-title`·`.regime-card`는 그대로다. 나머지 화면은 아직 기존 스타일이다(확대 여부는 시범 평가 후).

### 토큰 (`:root`, 테마 무관)
| 토큰 | 값 | 이유 |
|---|---|---|
| `--sp-1..5` | 4/8/12/16/24px | 간격을 5단계로 고정해 "카드 안 그룹 간 간격 일정"을 코드로 강제. 임의 px 금지 |
| `--r-card` | 14px | 12~16px 범위. 기존 8~10px보다 터치 UI에 가깝고 999px 필(버튼)과 구분됨 |
| `--fs-hero` 24 / `--fs-title` 17 / `--fs-body` 14 / `--fs-label` 12 | | 타입 스케일을 4단으로 제한. 12px 미만 글자 금지(기존 10~11px 보조글은 가독성 부족) |
| `--font-sans` | Pretendard Variable → system-ui | 한글·숫자 폭이 균일하고 tnum 지원, OFL. 가변 dynamic-subset(unicode-range)이라 쓰는 글리프 조각만 받고 `font-display: swap` |

### 타이포 규칙
- 위계: 라벨(12px, `--text-secondary`) → 핵심 숫자(24px/700, 자간 -0.02em) → 보조(12~13px, `--text-secondary`). 보조는 투명도가 아닌 토큰으로 흐리게. **정보 전달 글자에 `--text-muted` 금지**(라이트 3.5:1로 AA 미달, 비활성·캡션 전용).
- 섹션 제목 `.mt-title` 17px/700. 기존 15px 제목과 섞여 있는 것은 시범 한계.

### 숫자 규칙
- 모든 숫자 `font-variant-numeric: tabular-nums`; 표·리스트 값은 우측 정렬.
- 지수 = 천단위 콤마 + 소수 2자리, 등락률 = 절댓값 소수 2자리 + `%`, 방향은 ▲▼(상승 빨강/하락 파랑, 보합은 화살표 없이 secondary). 색만으로 방향을 전달하지 않는다.
- 금액(수급) = 백만원 입력을 `억`은 정수, 1조 이상은 `N.NN조`, 부호는 `+`/`−`(U+2212). 방향 라벨은 `▲ 순매수`/`▼ 순매도`. 핵심 숫자 자체는 기본 글자색(방향색은 화살표 쪽에만)이라 큰 숫자가 빨강·파랑으로 번지지 않는다.
- ▲▼는 가격·수급 방향 전용. 펼침 표시는 CSS 쉐브론을 쓴다(내러티브 행).

### 카드 규칙
- 카드 = `--surface` + 1px `--border` + `--r-card`, 그림자·그라데이션·blur 없음. 내부 패딩 16px, 그룹 간 8~12px.
- 한 카드에 숫자 하나만 크게: 변동성 레짐은 `라벨 배지 + 대표 rv + 보조 한 줄`만 먼저, 갭·윈도우별 rv·경고는 "자세히" 접기. 설명은 기존 모달.
- 목록은 낱개 카드 대신 한 덩어리 리스트(행 사이 1px 구분선)로 묶어 카드가 층층이 쌓이는 느낌을 없앤다(내러티브).
- 모바일(<640px): 타일 행은 가로 스크롤 스냅(158px 타일, 화면 끝까지 번지게 해 더 있음을 암시), 데스크톱은 3열. 페이지 탭(`.page-tabs`)은 가로 스크롤.
- 상태: hover(테두리 진하게)/active(칩 배경)/focus-visible(2px 링)/disabled, 로딩=스켈레톤(`.mt-skel`, reduced-motion이면 정지), 빈 상태=좌측정렬 점선 박스, 에러=경고색 박스+다시 시도.
